• A1. Тренажёр таблицы умножения: Написать программу, которая генерирует \(N\) случайных примеров на умножение. Она должна замерять время ответа, проверять корректность ввода (обрабатывать ошибки, если введено не целое число) и в конце выводить подробную статистику (общее/среднее время, количество и % правильных ответов).
• A2. Рисование фигур: Используя вложенные циклы, вывести на экран текстовые фигуры из символов #: сплошной прямоугольник (\(n \times m\)), правый прямоугольник-треугольник (\(n\) строк) и пустую рамку (\(n \times m\)).
• A3. Анализ сетевых пакетов: Создать программу для анализа качества связи по строке из 0 (потерян) и 1 (доставлен). Программа должна проверить корректность ввода, посчитать общее число пакетов, количество потерь, самую длинную серию подряд идущих нулей, процент потерь и выдать финальную оценку качества сети.
• A4. Валидатор кредитных карт: Разобрать готовый пример из Лекции 6, найти в нём ошибки (если они есть), исправить их и запустить работающий валидатор номеров карт.
